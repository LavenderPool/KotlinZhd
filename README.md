# ЖД вокзал

Мобильное приложение для работы с расписанием поездов и билетами. Можно найти рейс, выбрать место, забронировать или купить билет, а также управлять данными вокзала.

## Возможности

**Покупатель**
- Поиск рейсов по станциям и дате.
- Просмотр маршрута, остановок и свободных мест.
- Бронирование, покупка и отмена билетов.

**Сотрудник**
- Управление поездами, станциями, сотрудниками, расписанием, остановками и билетами.
- Поиск, добавление, редактирование и удаление записей.

Вход выполняется выбором роли без логина и пароля. Оплата демонстрационная — реальные деньги не списываются.

## Стек разработки

| Технология | Назначение |
| --- | --- |
| Kotlin | Язык разработки |
| Jetpack Compose и Material 3 | Интерфейс приложения |
| SQLite | Локальное хранение данных |
| Gradle | Сборка проекта |
| JUnit и AndroidX Test | Тестирование |

Поддерживается Android 7.1 (API 25) и новее. Приложение работает без сервера; данные сохраняются на устройстве и доступны обеим ролям.

## Запуск проекта

Откройте проект в Android Studio и запустите конфигурацию `app` на устройстве или эмуляторе. Для сборки APK из командной строки:

```bash
./gradlew assembleDebug
```

При первом запуске база заполняется демонстрационными данными. Даты рейсов отсчитываются от дня создания базы; чтобы заполнить её заново, очистите данные приложения в настройках Android.
